## 0. 一页结论

- **一句话**：选一张图，配一套武学，自动刷，掉东西，变强，再往更深、更高名次走；回来时读一封江湖信，知道下一步去哪。
- **核心循环**：选图 → 配招/配装 → 自动战斗 → 掉落/修为/声望 → 成长 → 推层/天机榜 → 新目标。
- **不是**：事件选择器、纯文字挂机、单机 demo。**系统深度优先，不做内容切片。**
- **骨架**：暗黑 3/4 的“刷层—掉落—变强—更高层”；流放之路的词条、辅助、地图词缀、赛季；九阴的内功、套路、实虚架气、离线修炼、风水宝地。
- **三条核心货币**：银两、修为、名望。门派声望、天机积分、材料、武学残页是次级资源。
- **七境九层**：7 个境界 × 9 层 = 63 个境界层；100–300 小时完成一生，赛季与归隐承接更长线。
- **八条养成线**：境界、内功、武学、心法/经脉、兵器/行头、门派/声望、同伴/羁绊、天机榜/江湖志。
- **默认常驻“江湖信息台”**：右侧 32% 左右，默认展开、可收起；默认页是“地图”，显示怪物、掉落、词缀、已刷时长、已得收获、目标掉落。
- **战斗不做动作表现**：自动演算 + 条件优先级；深度在战前配招、内功/心法/经脉、装备词条、同伴和敌方情报；战报负责“演出”。
- **反日常**：不做体力、广告翻倍、每日打卡。离线有上限，但不惩罚；超时自动歇脚。
- **下一步**：先把系统总表和数值模型做闭合，再做无 UI 的平衡模拟器；模拟器能跑出 3 套不同曲线且没有一套通吃，才开始做正式 UI 和内容。

**需要拍板的三个默认值**

1. 门派：一次只能加入一个，可花代价改换；已学武学保留，门派地位清零。
2. 天机榜：单机 NPC 榜，不做实时 PVP；赛季重置名次，不重置角色。
3. 归隐/开宗立派：作为远期终局，首版只留接口，不首发放出。

## 1. 设计支柱

### 1.1 画中江湖

原图不是背景，是世界的骨架。五个红印就是五章：

| 红印 | 章节主题 | 本地矛盾 | 主玩法 |
|---|---|---|---|
| 中原 | 天下之名 | 武林盟 vs 朝廷鹰犬 | 擂台、名望、武林大会 |
| 武当 | 剑与道 | 守旧道门 vs 入世剑宗 | 闭关、试炼、剑冢 |
| 西湖 | 人情与风雅 | 世家联姻 vs 书院清流 | 雅集、疗伤、情缘 |
| 扬州 | 钱与消息 | 漕帮 vs 盐商商会 | 押镖、黑市、听书 |
| 汉越墓 | 禁地与古谱 | 守墓人 vs 盗墓者 | 探墓、残页、高风险收益 |

每个地方不是刷怪点，而是有主人、有矛盾、有规矩的地方。玩家在这里刷，也在这里做选择。

### 1.2 武学成局

战斗几乎没有表演，但必须是一套可研究的“局”：内功属性、实虚架气、连招、破招、心法、经脉、装备词条、同伴、敌方意图。玩家战前做决定，战后看战报，下一次知道为什么能赢。

### 1.3 江湖有人

NPC 有立场、有记忆；门派有等级和专属武学；声望改变称呼、价格、任务和结局；同伴会同行、说话、有自己的任务。江湖味不是把按钮改成毛笔字，是**选择有后果**。

### 1.4 无限可刷

地图有层数、词缀、精英、首领；装备有词条、套装、传奇效果；天机榜有排名和赛季。刷是引擎，不是重复劳动；每次刷都要能掉到“改变 build 的东西”。

### 1.5 放置不空转

玩家不需要一直盯着，但回来必须看到三件事：**我强了多少、下一步是什么、谁在等我**。常驻信息台、离线江湖日志、下一目标卡，是放置游戏的前端体验替代品。

## 2. 体验目标与时间尺度

### 2.1 目标

| 项目 | 目标 |
|---|---|
| 单次主动游玩 | 3–8 分钟 |
| 每日回来 | 2–4 次 |
| 首次完整 build | 1–3 天 |
| 首个境界大突破 | 1–4 小时 |
| 首个宗师 | 2–4 周 |
| 一生（到归隐） | 100–300 小时 |
| 单赛季 | 8 周 |
| 长期留存钩子 | 天机榜、套装/绝学收集、门派/同伴结局、江湖志 |

### 2.2 时间尺度

| 时间 | 玩家在做什么 | 系统给什么 |
|---|---|---|
| 10 秒 | 看自动战斗、掉落 | 战报、数字、掉落光效/文字 |
| 3–8 分钟 | 配招、换装、收信、选下一张图 | 明确的变强、下一目标 |
| 1 小时 | 打首领、突破、换一套 build | 新层数/新武学/新地图 |
| 1 天 | 境界突破、门派 rank、套装 | 大数值 + 新选择 |
| 1 周 | 天机榜、同伴个人任务、新层 | 排名、剧情、稀有掉落 |
| 8 周 | 武林大会、赛季目标 | 新词缀/新规则/称号 |

**每次回来必须回答三个问题**：我强了多少？下一步是什么？谁在等我？

## 3. 资源与经济

### 3.1 三种核心货币

| 资源 | 作用 | 主要来源 | 主要消耗 | 上限/软上限 |
|---|---|---|---|---|
| 银两 | 通用钱 | 卖装备、悬赏、地图结算、离线 | 打造、淬炼、药、洗点、赶路 | 无硬上限，靠消耗回收 |
| 修为 | 武学成长 | 战斗、离线修炼、首通、事件 | 境界层数、内功层数、经脉 | 有存储上限，逼迫消费 |
| 名望 | 江湖地位 | 首领、擂台、首通、门派 | 境界试炼、地图/门派解锁、部分武学 | 按境界软锁 |

### 3.2 次级资源

| 资源 | 说明 |
|---|---|
| 门派声望 | 每个门派独立，等级：陌生/相识/友善/敬重/崇拜；用于 rank、商店、专属武学 |
| 天机积分 | 天机榜/武林大会产出，只换外观、称号、稀有收藏，不换战力 |
| 武学残页/整本 | 合成武学、提升熟练 |
| 心法注解 | 解锁/升级心法 |
| 内功秘籍 | 解锁内功 |
| 材料 | 打造、淬炼、突破 |
| 信物/礼物 | 同伴羁绊 |
| 丹药 | 战斗消耗、突破辅助 |

### 3.3 经济原则

- **不做交易行**。单机为主，避免经济被工作室和倒卖扭曲；所有掉落自己用。
- **银两必须有大 sink**：淬炼、洗点、打造、药、赶路。装备回收成材料，材料再进打造。
- **修为存储上限**：防止无限囤积后一次性跳过内容；上限随境界提升。
- **名望是门槛不是印钞**：名望只用于解锁和试炼，不直接买战力。
- **天机积分不碰战力**：只做外观/称号/收藏，避免 PVP 焦虑和 P2W。
- **离线收益 = 在线同图的 50–70%**：放置能玩，主动更优；不逼人上线。
- **不做体力、广告翻倍、每日签到墙**；可以用每周天机榜、门派周常作为软节奏，但不做“今天必须点完”的清单。

## 4. 八条养成线

### 4.1 总表

| # | 线 | 核心循环 | 主要产出 | 主要消耗 | 构筑作用 | 时间尺度 | 长线目标 |
|---|---|---|---|---|---|---|---|
| 1 | 境界 | 修为→层数→突破 | 属性、槽位、新地图 | 修为、名望、突破材料 | 战力地板 + 解锁 | 40–100h | 七境九层圆满 |
| 2 | 内功 | 收集→修炼→装备 | 属性、特殊效果 | 修为、秘籍 | 决定属性匹配/流派 | 每门 5–20h | 全内功收集 |
| 3 | 武学 | 残页→合成→熟练 | 招式、连招、绝技 | 修为、心得 | 主动 build 的核心 | 每门 5–20h | 全武学谱 |
| 4 | 心法/经脉 | 注解→装配→穴位 | 辅助效果、keystone | 修为、银两、经脉点 | 被动 build 的身份 | 10–40h | 多套经脉方案 |
| 5 | 兵器/行头 | 掉落→打造→淬炼 | 词条、套装、传奇效果 | 银两、材料 | 数值 + 词条 build | 持续 | 毕业套/稀有词条 |
| 6 | 门派/声望 | 任务→选择→rank | 专属武学、商店、称号 | 时间、贡献、选择 | 可选空间 + 身份 | 天/周 | 掌门/结局 |
| 7 | 同伴/羁绊 | 招募→礼物→任务 | 助战、羁绊技、剧情 | 时间、信物 | 战斗辅助 + 情感 | 天/周 | 全羁绊/结局 |
| 8 | 天机榜/江湖志 | 擂台→排名；探索→图鉴 | 称号、积分、记录 | 挑战、探索 | 验证 build/收束 | 赛季/长期 | 天下第一/题跋 |

### 4.2 各线说明

#### 4.2.1 境界

- **结构**：7 境 × 9 层 = 63 层。七境：初入江湖、三流、二流、一流、绝顶、宗师、传说。
- **升级**：每层消耗修为；每境第 9 层需要“突破”：修为 + 名望 + 突破材料 + 一场试炼/首领。
- **收益**：基础属性、每 3 层 1 点经脉点、每境解锁新槽位/新地图/新功能。
- **卡点**：突破试炼放在不同地点（武当演武、中原擂台、汉越墓生死关），让地图有功能，不只是刷怪。
- **时间目标**：初入 30–45 分钟；三流 1–3 小时；二流 4–8 小时；一流 1–2 天；绝顶 3–5 天；宗师 2–4 周；传说 4–8 周（占位，按每天 1–2 小时主动+挂机计）。
- **注意**：境界是地板，不是全部。不能让“境界高=必胜”；build 克制要能跨层赢。

#### 4.2.2 内功

- **收集**：门派内功、江湖内功、奇遇内功；每门 1–10 层，3/6/9 层解锁特效。
- **装备**：1 门主内功生效；v0.1 不做辅修，避免复杂度失控。辅修作为后续扩展。
- **属性**：阴、阳、刚、柔、太极。招式有属性；内功属性匹配时，对应招式 +20%；太极内功对所有属性 +10%；不匹配不惩罚。
- **特效**：每门内功一个标志性机制。例：
  - 纯阳无极功（太极）：招架成功回内力；气血低于 30% 时减伤。
  - 北冥神功（阴）：攻击吸取内力；内力高于 50% 时伤害提升。
  - 罗汉伏魔功（刚）：攻击提升、身法下降；会心时破甲。
  - 听雨心法（柔）：受击叠“雨意”，满层反击。
  - 玄阴经（阴）：攻击附带封穴/毒；对精英/首领效果衰减。
- **长线**：不同内功改变 build 的底层逻辑，不是纯数值。收集全内功是江湖志的一部分。
- **离线**：可设置离线修炼内功；地点“风水宝地”给加成（见 9.3）。

#### 4.2.3 武学

- **结构**：一门武学 = 4–6 个招式 + 1 个绝技 + 1 个被动。玩家从多门武学中选 **4 个招式 + 1 个绝技** 装配。
- **招式字段**：类型（实/虚/架/气）、属性（阴/阳/刚/柔/太极）、内力消耗、冷却、连招标签（起手/追击/终结）、状态、倍率。
- **熟练度**：每门 1–10；使用/消耗修为提升；3/6/9 级解锁变招或被动。
- **获取**：门派传授、首领首通、奇遇、残页合成；不做抽卡。
- **长线**：收集全武学谱；每门武学有独立故事和克制的“绝活”。
- **反设计**：不要做“纯 +5% 攻击”的技能树；每门武学至少要改变一个战斗决策。

#### 4.2.4 心法/经脉

- **心法**：辅助槽，1 个招式可挂 1 个心法，共 4 个。心法改变招式行为，例：
  - 追风：招式速度 +20%，伤害 -10%。
  - 裂甲：忽略 20% 防御。
  - 回气：命中回 5 内力。
  - 连绵：连招窗口 +1 回合。
  - 噬心：会心附加流血。
  - 守拙：气血低于 40% 时减伤 15%。
  - 借力：招架成功时反弹伤害。
- **经脉**：3 条分支（攻伐/固本/身法），共 36 节点 + 6 个 keystone。经脉点来自境界（每 3 层 1 点）和奇遇；洗点消耗银两/丹药。
- **keystone 示例**：
  - 以柔克刚：招架成功反弹 30% 伤害，但自身攻击 -10%。
  - 剑气纵横：连续使用剑招时，每段 +8% 伤害，最多 5 层。
  - 金钟罩：每场战斗首次致命伤害免疫，冷却 3 场。
  - 踏雪无痕：身法 +20%，先手时首招伤害 +30%。
- **长线**：多套经脉方案，针对不同地图/首领切换；不是一条线点到底。

#### 4.2.5 兵器/行头

- **槽位**：兵器、头冠、衣袍、护腕、鞋履、玉佩，共 6 件。
- **兵器类型**：剑、刀、拳/徒手、枪/棍、暗器。类型限制可用的武学，决定 build 方向。
- **稀有度**：凡、良、上、绝、神。
  - 凡：1 条词条；良：2；上：3；绝：4；神：4 + 传奇效果。
- **词条池**：
  - 前缀：攻击、气血、防御、身法、内力、会心。
  - 后缀：某武学伤害、某属性招式加成、状态概率、破招、连招、声望获取、银两获取。
  - 传奇效果：改变一个招式/机制，例如“揽雀尾反弹 +30%”“封穴对首领有效”“轻功后下一招必会心”。
- **套装**：每个地区 1–2 套，2/4 件套效果；套装给 build 方向，不是纯数值。
- **打造/淬炼**：打造底装 + 词条重铸/升级；淬炼 +1～+10；材料来自回收。洗练有保底，不无限赌。
- **掉落**：普通怪掉凡/良；精英掉上/绝；首领掉绝/神 + 套装保底；每张图有 2–3 件标志掉落，信息台可追踪。
- **长线**：毕业不是唯一目标；不同套装对应不同 build/地图。

#### 4.2.6 门派/声望

- **五门派**（玩家可加入一个）：武林盟（中原）、武当、清流书院（西湖）、漕帮（扬州）、守墓人（汉越墓）。
  - 每个门派有立场、rank、专属武学、商店、周常任务。
  - 一次只能加入一个；可花代价改换，已学武学保留，门派 rank 清零。
- **门派 rank**：门外、入门、内门、真传、长老、掌门（掌门为远期目标）。
- **声望等级**：陌生、相识、友善、敬重、崇拜。影响称呼、价格、任务、商店、结局。
- **选择**：帮助一方会降低另一方声望；关键事件会锁/开 NPC 线。不是所有门派都能“全崇拜”。
- **长线**：专属武学、门派结局、掌门/开宗立派。

#### 4.2.7 同伴/羁绊

- **数量**：8 名可招募同伴；1 名主战 + 2 名助威（被动/羁绊加成）。
- **招募**：剧情、门派、奇遇；不做抽卡。
- **羁绊**：1–10 级；礼物、同行、个人任务；3/6/9 级解锁助战技/被动/剧情。
- **战斗**：主战同伴自动释放 1 个助战技，有冷却；羁绊提升效果。
- **陪伴**：主界面/地图上出现墨影；战报里有台词；离线时可能寄信；个人任务改变结局。
- **角色**：剑客、医女、机关师、说书人、捕快、船娘、守墓人、刀客；每个有偏好地点/礼物。
- **长线**：全羁绊、个人结局、同伴与门派的交叉剧情。

#### 4.2.8 天机榜/江湖志

- **天机榜**：单机 NPC 榜，500–1000 名；每一名有名字、build、奖励；挑战下一名，胜利晋级。
  - 赛季 8 周：名次软重置，角色进度不重置；称号/外观保留。
  - 天机榜是 build 的验证场，不是战力扫描仪；低战力克制 build 可以越级。
- **武林大会**：赛季活动，带特殊规则（例：剑法 +20%、内功回复 -30%），独立榜；给称号/外观/稀有收藏，不给唯一战力。
- **江湖志**：地点、NPC、武学、怪物、事件、结局的图鉴/成就；完成度给奖励；最终生成题跋地图。
- **归隐/开宗立派**：宗师后开放；归隐保留 1 门绝学、1 名同伴羁绊、1 个称号，重开一生；开宗立派是远期门派经营层，首版只做接口。

### 4.3 八条线怎么互锁

```text
刷图/秘境
  → 掉落装备/残页/材料/信物 + 修为 + 名望 + 门派声望
  → 装备/武学/心法/经脉/内功/同伴 按需调整
  → 推更深层 / 打天机榜 / 做门派选择
  → 解锁新地图/新武学/新同伴/新结局
  → 回到刷图
```

- **装备/武学**决定“能不能打”。
- **内功/心法/经脉**决定“用什么方式打”。
- **门派/同伴**决定“有哪些牌可以选”。
- **境界**决定“地板和解锁”。
- **天机榜/江湖志**负责“为什么继续打”。

每条线都必须有“下一格”，而且下一格最好是新选择，不是纯 +5%。

## 5. 战斗系统

### 5.1 属性

| 属性 | 作用 | 主要来源 |
|---|---|---|
| 气血 | 生命 | 境界、内功、装备、同伴 |
| 内力 | 招式资源 | 内功、装备、心法 |
| 攻击 | 伤害基础 | 境界、武学、装备 |
| 防御 | 减伤 | 境界、内功、装备 |
| 身法 | 先手/闪避/连招 | 轻功、装备、经脉 |
| 会心 | 暴击率/暴击伤害 | 装备、经脉、内功 |

次级：破招、连招、状态命中/抵抗、内力回复。不要做成十几条一级属性；大部分放装备词条/心法里。

### 5.2 招式类型：实、虚、架、气

| 类型 | 作用 | 克制 | 被克制 | 说明 |
|---|---|---|---|---|
| 实招 | 主要伤害 | 虚招 | 架招 | 对气招有打断 |
| 虚招 | 破架/破防 | 架招 | 实招 | 伤害低，功能强 |
| 架招 | 招架/减伤/借力 | 实招 | 虚招 | 成功招架回内力/叠借力 |
| 气招 | 增益/减益/回气 | 无硬克制 | 实招打断 | 提供状态和资源 |

基础三角：**实克虚、虚克架、架克实**；气是功能位，被实招压制。这样自动战斗有明确的“读招—应对”，又不至于石头剪刀布到无脑。

### 5.3 意境/内功属性

- 招式属性：阴、阳、刚、柔、太极。
- 主内功属性与招式匹配：+20% 伤害/效果；太极内功所有属性 +10%；不匹配不加成、不惩罚。
- 内功特效是 build 的核心；属性只是第一层匹配，不是全部。
- 例：柔属性内功 + 招架/借力套路；刚属性内功 + 破甲/爆发；阴属性内功 + 封穴/毒。
- “诡”是敌人行为/禁术的标签，不属于内功五属性；玄阴经主属性为阴。

### 5.4 连招/破招

- 连招标签：起手、追击、终结。
- 起手命中后，追击招有额外效果；终结招消耗连击层数，打爆发。
- 敌方“杀招”有预警（蓄力/意图）；用对应类型（如虚破架、架挡实）成功应对 = 破招，获得借力/内力/连击。
- 连招/破招是战斗深度的主要来源，不是单纯堆攻击。

### 5.5 心法、内功、经脉、同伴

- 4 个招式各挂 1 个心法；心法改变行为，不是纯数值。
- 1 门主内功；1 个轻功；1 个同伴助战；4 个招式 + 1 个绝技。
- 经脉 3 分支 + 6 keystone；至少 3 套可行方案。
- 同伴助战技自动释放；羁绊等级提升效果。

### 5.6 自动战斗：条件优先级

玩家不操作战斗，战前配置最多 6 条规则；系统按顺序判断。

示例：

1. 敌方正在蓄力杀招，且我有虚招 → 用虚招破招
2. 敌方有架招状态 → 用虚招破防
3. 内力 ≥ 60 → 用绝技
4. 连击 ≥ 3 → 用终结技
5. 气血 < 40% → 用架招/回气
6. 否则用起手招攒内力

提供 3 套官方预设（稳健/爆发/克制），硬核玩家可以细调。自动战斗有 1x/2x/4x 加速；战报保留。

### 5.7 伤害公式（v0.1 占位）

```text
基础伤害 = 攻击 × 招式系数 × (1 + 内功匹配加成)
克制倍率 = 实/虚/架/气克制 × 连招/破招 × 会心
最终伤害 = 基础伤害 × 克制倍率 × (1 - 防御 / (防御 + K))
```

- K 随境界/地图等级增长；防御是减伤，不是无敌。
- 会心 1.5 倍；破招额外 20%；连招终结技按层数加成。
- 多条乘区不要超过 4 类，避免数值失控。
- 战力是估值：`气血/10 + 攻击×2 + 防御×1.5 + 身法×1 + 会心×...`，只做参考；真实胜负看克制/优先级。

### 5.8 敌人、失败、复盘

- 敌人有流派/意图/关键招；精英有词缀，首领有阶段（50% 狂暴/换招）。
- 战斗 6–12 回合；首领 15–25 回合；一场 15–40 秒，可加速。
- 失败：损失少量银两/受伤，不掉已得装备；回西湖疗伤；不死亡惩罚。
- 战报最后给“复盘建议”：没破招、内力不足、被克制、装备命中不够。
- 提供“推演/木桩”：不消耗资源，测试优先级和 build。

### 5.9 示例 build

| build | 内功 | 核心招式 | 心法 | 经脉 | 同伴 | 强项/弱点 |
|---|---|---|---|---|---|---|
| 太极反伤 | 太极/柔 | 云手、揽雀尾、白鹤亮翅、四两拨千斤 | 借力、回气、守拙、连绵 | 固本/以柔克刚 | 医女 | 强于刚/爆发；弱于封穴/持续毒 |
| 破军爆发 | 刚 | 力劈华山、横扫千军、破军斩、血战八方 | 裂甲、追风、噬心、狂意 | 攻伐/剑气纵横 | 刀客 | 强于柔/召唤；弱于架招/反伤 |
| 玄阴封穴 | 阴 | 玄阴指、封穴手、蚀骨掌、万蛊噬心 | 噬心、裂甲、回气、连绵 | 身法/踏雪无痕 | 机关师 | 强于快/多段；弱于高防/解控 |

### 5.10 战斗深度检查表

- 是否存在至少 3 套胜率接近、打法不同的 build？
- 是否存在“低战力靠克制越级”的可行窗口？
- 是否每张图/每个首领都需要调整至少一个配置？
- 失败后玩家是否能说出“我下次改什么”？
- 自动战斗是否会出现“同一套优先级通吃”？
- 数值成长是否让旧 build 有退场，但不是废掉？

## 6. 掉落与装备

### 6.1 槽位与稀有度

| 槽位 | 主属性 | 备注 |
|---|---|---|
| 兵器 | 攻击/武学加成 | 类型限制武学 |
| 头冠 | 防御/气血 | 可出会心/内力 |
| 衣袍 | 防御/气血 | 套装核心 |
| 护腕 | 攻击/身法 | 连招/破招词条 |
| 鞋履 | 身法/防御 | 轻功/先手 |
| 玉佩 | 内力/会心 | 稀有传奇位 |

稀有度：凡/良/上/绝/神；词条数 1/2/3/4/4+传奇。

### 6.2 词条预算

- 每件装备有“词条预算”，随物品 tier 提升；稀有度决定词条数量。
- 词条有 tiers 1–5；高 tier 需要高地图层/首领。
- 词条池分：基础属性、武学加成、意境加成、状态、资源、声望。不要全是伤害词条。
- 传奇效果控制在 12–20 个；每个改变一个招式/机制，不做纯数值传奇。
- 套装 2/4 件；不做 6 件套，避免锁死。

### 6.3 掉落与保底

- 普通怪：凡/良为主，小概率上。
- 精英：上/绝为主，小概率神。
- 首领：绝保底，神概率；首通必掉 1 件标志装备/武学。
- 每张图 2–3 件标志掉落；信息台可设置“目标掉落”，显示掉率/保底进度。
- 连续 N 次未出稀有 → 软保底；具体 N 由模拟器调。
- 自动分解/拾取过滤：按稀有度、词条、套装过滤；避免背包地狱。

### 6.4 打造、淬炼、回收

- 打造：底装 + 材料 + 银两；可重铸词条，有保底。
- 淬炼：+1～+10；只加基础属性，不失败碎装（避免挫败）。
- 回收：装备→材料；材料→打造/淬炼。
- 洗点：经脉/武学配置可花银两重置；不卖“洗点卡”。

### 6.5 装备与江湖味

- 套装不是“数值套装”，要有门派/地点故事：听雨套、漕帮套、剑冢套、古墓套。
- 兵器有名字和来历；传奇效果写成江湖典故，不是“+30% 火伤”。
- 装备不绑定职业，绑定 build；换武器=换玩法。

- 层数越高：掉落 tier 越高、词缀越多、敌人 AI/属性越强；不单纯堆血量。
- 首通首领解锁下一层/下一图/新武学/新 NPC。

### 7.3 NPC、事件、同伴

- 每个地区 4 名主要 NPC（门派掌门/地方人物/对手/潜在同伴）；总计 20 名。
- 每个地区 8–12 个事件；总计 50–60 个；包含随机事件、连锁事件、门派选择。
- 8 名同伴；每个地区至少 1 名，剩余通过奇遇/结局解锁。
- 事件不是独立弹窗：它接声望/门派/同伴/武学/地图；选择有后果，江湖录自动记录。
- 奇遇：满足条件触发，给内功/武学/同伴/称号；不做抽卡。

## 8. 放置与离线

### 8.1 行止

- 玩家选择：地图 + 层数 + 自动策略（推层/刷材料/刷目标掉落）+ 停止条件（背包满/稀有掉落/首领失败/时间到）。
- 在线：自动战斗，可加速/跳过；可随时改配置。
- 离线：按时间戳模拟；上限 8–12 小时；超过上限后“在客栈歇脚”，不罚收益。
- 离线收益约为在线同图的 50–70%；主动操作更优，但不上线不会掉队。
- 不做体力；不做广告翻倍；不做“必须上线点一下”的日常。

### 8.2 离线江湖日志

- 回来先看到一封“江湖日志/江湖帖”：
  - 本次离线时长、战斗场次、胜负、掉落、修为、声望变化。
  - 1–3 个需要选择的事件（不堆几十条红点）。
  - 1 个“下一步建议”：突破、打首领、换图、见某个 NPC。
- 事件选择影响声望/关系/资源；其余自动结算。
- 江湖日志是“前端体验”的替代品：用文字、数字、关系变化制造回来的情绪。

### 8.3 风水宝地

- 来自九阴的环境修炼系统；用于本作的“地点差异化”。
- 每个地区/地图有风水属性：山、林、水、洞、雪、市。
- 不同内功/武学在对应环境修炼有加成；例：
  - 武当（山/雪）：太极/阳刚内功 +20%。
  - 西湖（水/市）：柔/阴内功 +20%，但市井嘈杂使刚猛内功 -10%。
  - 汉越墓（洞）：阴/禁术 +20%，但疗伤效果 -20%。
  - 扬州（市）：银两/情报 +20%，内功修炼 -10%。
  - 中原（山/林）：均衡，名望 +10%。
- 这让“在哪挂机”不只是收益数字，也是 build 的一部分。

### 8.4 反日常原则

- 不做每日任务清单；用每周天机榜、门派周常、世界事件做节奏。
- 不做扫荡券；已通关层用自动重复/离线结算，不消耗付费资源。
- 不做限时冲榜逼氪；赛季奖励以称号/外观/收藏为主。
- 离线是主玩法，不是惩罚。

## 9. 常驻信息台（UI 规格）

### 9.1 布局

- 默认“案头”态：地图画页 68% + 右侧信息台 32%；默认展开，可收起。
- 收起“展卷”态：地图全幅，仅保留窄轨图标和未读徽章。
- 信息台是纸卷/账本风格，不是白色侧边栏；5 个 tab：
  - 地图（默认）、人物、武学、行囊、江湖。
- 顶部：银两、修为、名望、天机榜排名、江湖帖徽章、设置。
- 底部：行止/战况状态带 + 展开战报 + 主按钮（启程/挑战/收信）。
- 地图打开时保证五枚红印可见；收起后恢复全幅。避免顶栏压住“中原/武当”红印。

### 9.2 地图页（默认）

必须有：

- **当前地图**：地区、地图名、层数、危险度、推荐境界、地图词缀。
- **怪物**：名称、流派（行为风格：刚/柔/快/诡，与内功五属性不是同一层）、等级、掉落、精英/首领标记。
- **掉落表**：装备、武学残页、内功秘籍、材料、信物；可设“目标掉落”。
- **刷取统计**：在此已刷时长、战斗场次、胜率、银两、修为、稀有掉落数量、目标掉落进度。
- **操作**：换层、换图、自动挑战、停止条件、拾取过滤、离开。
- **本地 NPC/事件**：谁在这里、有什么传闻、未读事件。
- **数据更新**：时间/击杀/掉落实时刷新；不要每次打开都重新加载。

### 9.3 其他 tab

- **人物**：境界、内功、属性、6 件装备、同伴、称号、战力拆解、声望总览。
- **武学**：4 招 + 1 绝技 + 1 轻功、4 个心法、熟练度、优先级、3 套预设、推演。
- **行囊**：最近掉落、材料、秘籍、信物、拾取过滤、自动分解。
- **江湖**：门派/声望、NPC 关系、天机榜、江湖志、下一目标、江湖录。
- **江湖帖**：未读事件/离线日志/悬赏，独立徽章，不占 tab。

### 9.4 手机约束

- 16:9 基准，真实测试 844×390；右侧面板宽度 32% 时正文 ≥14px。
- 刘海/底部 Home 条留白；主要按钮在拇指区。
- 信息台可收起，但不默认收起；记住玩家上次状态。
- 不以“字号缩小”换信息量；必要时用二级页/展开，不用 8px 字。
- 颜色对比符合可读性；纸墨风格不等于低对比。

## 10. 数值节奏（v0.1 占位目标）

### 10.1 境界曲线

| 境界 | 层数 | 目标时间 | 主要解锁 |
|---|---|---|---|
| 初入江湖 | 1–9 | 0–45 分钟 | 基础战斗、第一门武学、第一张图 |
| 三流 | 10–18 | 1–3 小时 | 内功、门派、第一张精英图 |
| 二流 | 19–27 | 4–8 小时 | 心法/经脉、第一套套装、同伴 |
| 一流 | 28–36 | 1–2 天 | 地图词缀、天机榜、第二张地区 |
| 绝顶 | 37–45 | 3–5 天 | 传奇效果、门派 rank 3、深层图 |
| 宗师 | 46–54 | 2–4 周 | 武林大会、专属武学、终局试炼 |
| 传说 | 55–63 | 4–8 周 | 归隐/开宗接口、全图鉴目标 |

### 10.2 成长节奏

- 前 30 分钟：5–8 次可见升级/掉落；每 2–3 分钟有反馈。
- 1 小时：至少一次“换 build/换图/打首领”的选择。
- 1 天：至少一次境界/门派/套装的大推进。
- 1 周：至少一个新地图/新武学/新同伴/新 rank。
- 每 10 分钟：至少一条养成线有可见变化。
- 每小时：至少一次二选一决策（装备/心法/门派/同伴）。
- 每天：至少一次“大目标”推进（境界/天机榜/套装）。
- 不允许连续 2 小时无有意义掉落；用保底/目标掉落解决。

### 10.3 经济时间（占位）

- 一次 10 分钟挂机 ≈ 下一件小 upgrade 的 20–40%。
- 一件“上”装 ≈ 30–60 分钟目标刷取。
- 一次淬炼 +1 ≈ 20–40 分钟银两。
- 一次境界突破 ≈ 1–4 小时（含试炼）。
- 后期成本指数上升，但用新地图/新 tier 的收益抵消；避免“挂 1 天只够点一下”。

### 10.4 占位公式

- 境界层数成本：`C(n) = C0 × 1.12^(n-1)`，每 9 层一次突破；具体系数由模拟器调。
- 内功层数成本：`C(n) = C0 × 1.22^(n-1)`；3/6/9 层是断点。
- 装备淬炼：`C(n) = C0 × 1.35^(n-1)`，+10 封顶。
- 离线收益：在线同图的 50–70%，上限 8–12 小时。
- 掉落：普通/精英/首领分档；保底阈值由模拟器调；不做纯随机无保底。
- 所有数值在模拟器里跑 100–500 小时再定，不在文档里锁死。

## 11. 技术架构与实施顺序（不做切片）

### 11.1 模块

- `core/`：纯 TS 模拟层——战斗、掉落、经济、境界、事件、离线。
- `data/`：地点、地图、怪物、武学、心法、装备、NPC、事件、门派；数据驱动。
- `sim/`：无 UI 平衡模拟器，跑 bot/曲线/胜率/经济。
- `ui/`：React + CSS；地图、常驻信息台、战报、面板。
- `save/`：localStorage、版本迁移、导出/导入。
- `tests/`：公式单测、离线边界、掉率分布、存档迁移。

### 11.2 平衡模拟器（关键）

- 输入：build、地图、层数、优先级、时间。
- 输出：胜率、平均回合、掉落/小时、修为/小时、银两/小时、成长曲线。
- 跑 3 类 bot：稳健、爆发、克制；各 100 小时。
- 验收：至少 3 套 build 在不同阶段有竞争力；没有一套 >60% 通吃；没有“2 小时无成长”的段。
- 模拟器是“深度引擎”，不是游戏切片。

### 11.3 分阶段（每阶段是一整层，不是内容切片）

| 阶段 | 产出 | 验收 |
|---|---|---|
| 0 | 本总表 + Excel 数值表 | 系统闭合，能评审 |
| 1 | 数据 schema + 模拟器 | 可跑 100 小时曲线，无 UI |
| 2 | 战斗/掉落/经济核心 | 3 套 build 有差异，经济不崩 |
| 3 | 完整 UI 外壳 + 常驻信息台（先用占位数据） | 844×390 可读，数据实时 |
| 4 | 5 地区内容生产 | 每区一章，地图/首领/武学/事件齐 |
| 5 | 门派/同伴/天机榜/江湖志 | 长期目标闭环 |
| 6 | PWA/存档/音效/优化 | 手机可安装、离线可玩 |

### 11.4 技术栈

- Vite + React + TypeScript + Zustand；CSS 做纸墨 UI；SVG/Canvas 只做氛围/地图细节。
- 纯 TS 模拟层，UI 不持有规则；所有规则可测试。
- 内容 JSON/TS；Zod 校验；事件 DSL；确定性种子。
- localStorage + 导出/导入；云存档后置。
- PWA：manifest、service worker、横屏提示、safe-area；iOS 不能强制锁方向，做提示。
- 图片：1536 宽 WebP；高分屏准备 2x；地图页用响应式 object-position，避免红印被面板盖住。

## 12. 内容生产与预算

### 12.1 地区生产模板

每个地区必须交齐：

- 1 个门派/阵营矛盾
- 3 张地图（每张 4–6 怪物 + 1 首领）
- 2–3 门武学 / 1–2 门内功
- 4 名主要 NPC（含 1 名潜在同伴）
- 8–12 个事件（含 1 条连锁线）
- 1 套装备 + 1 个传奇效果
- 1 个地方志（历史/风俗/传闻）
- 1 个门派 rank 奖励树

### 12.2 写作管线

- 地区圣经 → 事件表 → 数据文件 → 校验 → 模拟器验证。
- 事件必须绑定系统效果（声望/关系/物品/武学/地图），不能只有文本选项。
- 每个事件 80–150 字；关键 NPC 事件可 300 字。
- 先写 1 个地区的 10 个事件做“味道样板”，但不要把它当切片；系统总表先闭合。

### 12.3 IP 原则

- 只借系统结构：内功、套路、实虚架气、奇穴、声望、珍兽/同伴、词条、地图词缀。
- 不借：金庸/古龙人物、门派专属名称、已有游戏武功名、剧情。
- 历史地名（武当、西湖、扬州、中原）可用；越墓是虚构处理。
- 所有 NPC/武学/门派名原创。

## 13. 风险与待拍板

### 13.1 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| 复杂度 | 八条线 + 词条可能让玩家看不懂 | 分层解锁；默认预设；信息台只显示关键 |
| 信息台太窄 | 32% 面板在手机上可读性差 | 14px 下限；二级页；可收起；844×390 实测 |
| 数值失控 | 多乘区/多线膨胀 | 模拟器；软上限；乘区≤4 类 |
| 内容量 | 5 区 × 15 图 × 50 事件 | 地区模板；数据管线；先闭环系统 |
| 单机天机榜 | 缺少真人竞争 | NPC 榜 + 赛季 + 称号；不做实时 PVP |
| 赛季重置 | 玩家反感清空 | 只重置名次，不重置角色 |
| IP | 参考作品有版权 | 只借结构，全部原创命名 |
| 静态画 | 长期视觉疲劳 | 词缀/天气/地图 UI 叠加；不重绘原图 |

### 13.2 待拍板

| 问题 | 选项 | 我的建议 |
|---|---|---|
| 门派 | 一次一个 / 可多修 | 一次一个，可改换；保留已学武学 |
| 天机榜 | NPC 榜 / 真人榜 | NPC 榜，避免后端和 PVP 焦虑 |
| 赛季 | 重置名次 / 重置进度 | 只重置名次和赛季奖励 |
| 招式槽 | 4+1 / 6+1 | 4 招 + 1 绝技，深度够、UI 不炸 |
| 出身 | 固定主角 / 3 种出身 | 3 种出身，给开局和事件差异 |
| 同伴美术 | 立绘 / 墨影+名章 | 墨影+名章+信件，统一且省美术 |
| 归隐/开宗 | 首发 / 远期 | 远期，首版留接口 |
| 商业化 | 买断 / 免费+外观 | 买断或免费+纯外观；不做广告/抽卡 |
